::: tip 枚举变量定义格式
- enum　枚举名　{枚举元素1,枚举元素2,……};
:::
```java
public enum State {
    WORK,          // 工作中
    SHORT_BREAK,   // 短休息
    LONG_BREAK     // 长休息
}

public enum TimerMode {
    COUNTDOWN,     // 倒计时（25:00 → 0:00）
    STOPWATCH      // 正计时（0:00 → 往上加）
}
//也可以用 int 常量（比如 0=工作, 1=短休, 2=长休）
```

| 常量                  | 值     | 含义            |
| ------------------- | ----- | ------------- |
| WORK_SECONDS        | 25*60 | 工作时长 25 分钟    |
| SHORT_BREAK_SECONDS | 5*60  | 短休            |
| LONG_BREAK_SECONDS  | 15*60 | 长休            |
| CYCLE_LENGTH        | 4     | 每四个番茄钟一个长休    |
| MIN_WORK_SECONDS    | 30    | 最低打卡时间（测试30s） |


```java
//定义"时间规则" 
private static final int WORK_SECONDS = 25 * 60;       // 工作 25 分钟
private static final int SHORT_BREAK_SECONDS = 5 * 60;  // 短休息 5 分钟
private static final int LONG_BREAK_SECONDS = 15 * 60;  // 长休息 15 分钟
private static final int CYCLE_LENGTH = 4;              // 每4个番茄钟长休息
private static final int MIN_WORK_SECONDS = 30;         // 最低打卡 30 秒
```

###### Timeline — 实现"每秒跳一次"
- JavaFX教程[ToggleButton（开关按钮） - 《JavaFX 教程中文翻译》 - 极客文档](https://geekdaxue.co/read/javafx-tutorial-cn/docs-basic-control-togglebutton.md)
``` java
public PomodoroTimer() {
    // 创建一个每1秒触发一次的定时器
    timeline = new Timeline(new KeyFrame(Duration.seconds(1), e -> tick()));
    timeline.setCycleCount(Timeline.INDEFINITE);  // 无限循环
}
```

```java
private void tick() {
    if (mode == TimerMode.STOPWATCH) {
        // 正计时模式：数字往上加
        elapsedSeconds++;
        if (state == State.WORK) {
            workElapsedSeconds++;
            // 检查是否达到最低打卡时间
            if (!minWorkReached && workElapsedSeconds >= MIN_WORK_SECONDS) {
                minWorkReached = true;
                // 可以打卡
                if (onMinWorkReached != null) Platform.runLater(onMinWorkReached);
            }
        }
        if (onTick != null) onTick.run();  // 通知 Controller 更新时间显示
    } else {
        // 倒计时模式：数字往下减
        if (remainingSeconds > 0) {
            remainingSeconds--;
            // ... 同样的打卡检查逻辑 ...
            if (remainingSeconds == 0) {
                onComplete();  // 时间到了！切换到休息
            }
        }
    }
}
```
###### 回调机制

💡runnable是什么？[彻底搞懂Java中的Runnable和Thread-腾讯云开发者社区-腾讯云](https://cloud.tencent.com/developer/article/2342037)
::: tip
Runnable 做的事情 = () -> { 要执行的代码 };
:::

```java
// Timer 里定义了 4 个"回调槽位"
private Runnable onTick;              // 每秒更新界面
private Runnable onWorkComplete;      // 工作结束 → 通知界面切换到休息
private Runnable onBreakComplete;     // 休息结束 → 通知界面回到工作
private Runnable onMinWorkReached;    // 达到30秒 → 通知界面解锁打卡按钮
```

```java 在控制器中插入具体行为
timer.setOnTick(() -> timerLabel.setText(timer.getFormattedTime()));
// 意思是：每秒把最新时间显示到界面上

timer.setOnWorkComplete(() -> {
    dataManager.recordPomodoro();           // 记录一次完成
    dataManager.addPoints(10);              // 加10积分
    modeLabel.setText("☕ 短休息时间！");     // 改界面文字
    // ...
});
```
